# Senpai — The Endless Chase

A lightweight browser-playable endless-runner prototype inspired by classic lane-based runner games. It uses original, stylized canvas-drawn anime-inspired characters rather than the uploaded reference images as rigged 3D models.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For the best experience, use a local static server (for example VS Code Live Server) or deploy the folder to GitHub Pages / Vercel.

## Controls
- Swipe left/right to change lanes; swipe up to jump; swipe down to slide.
- On-screen controls are also available.
- PC: Arrow keys or WASD; Space / Up to jump; Down to slide; Escape to pause.

## Included
- Endless Run, Missions, Story Mode, and Daily Challenge menu options.
- Three-lane perspective road with turns, gaps, barriers, coins, and four rotating environments.
- Chase meter, score, coins, pause/restart, sound effects, and catch ending.
- Responsive mobile and desktop layout.

## Important prototype notes
- This is a playable 2D canvas pseudo-3D prototype, not a production-grade full 3D game.
- Character art is simplified and drawn in code; the provided character reference images are not embedded or converted into animated 3D models.
- Voice lines are displayed as dialogue with simple synthesized sound cues; recorded voice acting is not included.
- Modes are prototype variations of the endless-run core; full mission progression, persistent saves, real voice acting, and advanced 3D assets would be future development.
- Internet is only used to load the optional Nunito font. The game itself does not require an account or backend.
